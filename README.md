 # OpenVapeCN
  
非营利的 Minecraft 开放技术组织。

我们致力于通过自由软件，让每个人都能平等地阅读、研究、修改和分享代码。

如果 Github 由于某些原因不可用，您可以在 Gitee 上继续追踪我们的更新。

#### Gitee镜像仓库: https://gitee.com/OpenVape

## 参与贡献

我们欢迎代码、文档、测试、翻译和研究成果。

参与项目前，请阅读对应仓库的贡献指南、许可说明和研究边界。提交内容即表示您确认自己有权贡献相关材料，并同意按照该仓库声明的许可证进行发布。

请保持技术讨论理性、公开和可验证，同时尊重玩家、开发者、服务器社区及原作者的合法权益。
